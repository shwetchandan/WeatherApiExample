# 🌦️ Weather App

A simple Android weather application built using **Kotlin** with **MVVM architecture**.

This project demonstrates API integration, local data handling, repository pattern, asynchronous programming, and reactive UI state management.

## 🛠️ Tech Stack

- **Kotlin**
- **MVVM Architecture**
- **Retrofit** – REST API integration
- **Kotlin Coroutines** – Asynchronous operations
- **StateFlow** – UI state management
- **ViewModel**
- **Repository Pattern**
- **Android SDK**

## ✨ Features

- 🌤️ Fetch weather information from API
- 🔄 Handle loading, success, and error states
- 🌐 Retrofit-based API integration
- ⚡ Coroutine-based background operations
- 🏗️ MVVM + Repository architecture
